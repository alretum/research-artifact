Export for the quality benchmark

Writes every completed item as benchmark input and downloads it as a zip. No model calls, so this is free and repeatable. Quality is judged by the external benchmark rather than here, because this pipeline's own filter runs on the model being tested.

The benchmark's coverage and homogeneous-options metrics compare a whole quiz against its source material, so the per-topic choices keep one quiz to one lecture. The generated config disables those two metrics for the coarser choices.
Rejected items are kept deliberately, so comparing the two costs nothing. Choose separate files if you need the two quiz-level metrics to describe one decision rather than a mixture.

The zip contains quizzes/, instructions/ and a benchmark.yaml already pointing at both. Fill in an evaluator model before running it — the config leaves it blank because a model that generated or filtered these items cannot independently judge them.
